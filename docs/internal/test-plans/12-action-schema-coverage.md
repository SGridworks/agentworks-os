## Steps
1. Clone repo and install deps: `pnpm install`.
2. Run the dedicated test file: `pnpm exec vitest run tests/integration/action-schema-coverage.test.ts`.
3. Verify all tests pass (0 failures).
4. Capture output and assert that the hash chain generated by `buildPolicyDecision` is deterministic.
5. Record coverage report (must be ≥ 80% for new code).

## Acceptance Criteria
- All 100 individual tests in `action-schema-coverage.test.ts` pass.
- Coverage report shows ≥ 80% line coverage for the `policy-engine` package.
- No uncaught exceptions; hash values are consistent across runs.
- The test suite completes within 2 minutes on a clean Mac Mini.

## Adversarial Checks
- Include tests that feed malformed `action_kind` strings (path traversal, null bytes, overly long strings) and assert schema validation rejects them.
- Verify that missing required data fields trigger `route_to_review` or `block` based on pack disposition.
