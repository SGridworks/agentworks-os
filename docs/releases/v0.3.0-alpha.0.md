# AgentWorks OS v0.3.0-alpha.0 Release Notes

Date: 2026-06-07
Status: Public release candidate
Baseline: `upstream/main` at `e9ceed665ed1e6f93b2267460eb8e15e78937584`

## Highlights

- Shared AWOS vault metadata index and daemon metadata endpoint.
- AWOS-native product surface cleanup and forbidden-reference scanner.
- Native workflow engine with versioning, checkpoints, waits, replay, resume, cancel, evidence packs, and self-heal proposals.
- Dispatch queue recovery states for waiting, dead-letter, cancellation, and retry handling.
- Public release safety scanner for local paths, private tenant identifiers, and private project names.
- Monorepo versioning through `VERSION` plus package manifest consistency checks.

## Migration Notes

This release branch is prepared as curated patchsets against `upstream/main`. Open a public-release PR from the branch after local verification passes.

Required patchset boundaries:

1. Vault metadata and AWOS-native reference cleanup.
2. Native workflow engine and dispatch recovery.
3. Open-source release hygiene: versioning, license, changelog, safety checks, and public migration exclusions.
4. Installer/package validation updates.

## Public Data Boundary

The public release must exclude every path in `.public-releaseignore`, including local agent prompts, internal strategy files, handoff notes, incident notes, and generated local state.

Before opening the public PR, run:

```bash
pnpm validate:release
```

Do not publish if `pnpm check:public-release` fails.
